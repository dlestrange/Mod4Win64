# Mod4Win64

A modern Windows/Qt revival of the classic Mod4Win module player, powered by libopenmpt.

## Windows release

The Windows x64 release branch includes a custom green LCD-style **64** icon
(embedded in the executable) and a PowerShell script to build a portable ZIP.

See [Windows release instructions](docs/RELEASING-WINDOWS.md) for the
Release CMake build, windeployqt deployment, libopenmpt DLL requirements,
clean-machine testing and third-party licence notes.

The portable package is generated locally in the ignored `dist/` folder.
